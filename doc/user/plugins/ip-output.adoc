=== ip (output)

[.cmd-header]
UDP/IP unicast or multicast output

This output plugin sends TS packets using UDP/IP, multicast or unicast.

Each UDP datagram is filled with one or more TS packets (see option `--packet-burst`).
By default, the datagrams contain TS packets without any extra information or encapsulation.
Use the option `--rtp` to generate RTP datagrams.

Using this plugin forces `tsp` and all plugins to use their real-time defaults (see the reference documentation for tsp).

[.usage]
Usage

[source,shell]
----
$ tsp -O ip [options] address:port
----

[.usage]
SMPTE forward error correction

With `--rtp`, use `--fec=1` for SMPTE ST 2022-1 column FEC (1D) or `--fec=2` for column and row FEC (2D).
A bare `--fec` selects 2D. Media use the specified even UDP port N; columns use N+2 and rows use N+4.
All streams use the same destination IP address, UDP source port, local interface, TTL, TOS and multicast settings.
Choose a destination port with room for the enabled parity streams.

The ST 2022-2 media profile requires payload type 33 and at most seven 188-byte or 204-byte TS packets per RTP datagram.
RTP sequence, SSRC and timestamp options remain available. `--enforce-burst` makes the media payload size consistent;
a final short burst is still transmitted and can participate in FEC without padding.

`--fec-columns` sets L, the number of columns, and `--fec-rows` sets D, the number of rows.
The default is 4 by 4. Supported values are 1 <= L <= 20, 4 <= D <= 20, and L * D <= 100.
Two-dimensional FEC additionally requires L >= 4. Matrix members are RTP datagrams, each containing one or more TS packets.
Column parity can correct bursts of up to L missing datagrams; row parity additionally corrects isolated losses.
Payload bandwidth overhead is 1/D for 1D and 1/D + 1/L for 2D, excluding additional headers.

Output follows the aligned-matrix traffic shaping in ST 2022-1 Annex C.
Row parity immediately follows its last protected media packet. Completed columns are interleaved with media from the next matrix,
between L and L * D media-packet intervals after their last protected packet. Media are not delayed or copied into a matrix buffer.
At shutdown, partial groups and delayed columns that require future media are discarded.
No extra TS packets are manufactured and no shortened-NA or prematurely transmitted parity is emitted;
the final media datagrams may therefore lack column protection. Configure the receiver's FEC buffer and latency accordingly.

[source,shell]
----
$ tsp -I file stream.ts -P regulate -O ip 239.1.2.3:5000 --rtp --fec=2 --fec-columns 10 --fec-rows 10
----

[.opt]
*--fec*[=1|2]

[.optdoc]
With `--rtp`, generate column FEC (1) or column and row FEC (2, the default).
Requires the ST 2022-2 media profile and an even destination port.

[.opt]
*--fec-columns* _count_

[.optdoc]
Set the number of columns L, from 1 to 20 (at least 4 in 2D mode). The default is 4.
Requires `--fec`; columns times rows must not exceed 100.

[.opt]
*--fec-rows* _count_

[.optdoc]
Set the number of rows D, from 4 to 20. The default is 4.
Requires `--fec`; columns times rows must not exceed 100.
